## Running Locally

1. Clone the repo:
   ```bash
   git clone https://github.com/Sandy16-06/My-Portfolio-main.git
   ```
2. Open the `Portfolio-main` folder.
3. Open `index.html` directly in your browser, or serve it locally:
   ```bash
   cd Portfolio-main
   python -m http.server 8000
   ```
   Then visit `http://localhost:8000`.

## Deployment

This site is deployed via **GitHub Pages** from the `Portfolio-main` folder of the `main` branch. Any changes pushed to `main` are reflected automatically at the live site link above (may take a minute or two to update).
